Add a pre-commit hook block to `lefthook.yml` that runs `dart format . --line-length 80` and `flutter analyze --fatal-infos --fatal-warnings` before every commit, so any formatting drift or analyzer warning blocks the commit locally instead of surfacing later in CI. Install lefthook (`dart pub global activate lefthook` or via the project's dev tooling) and run `lefthook install` once to wire up the git hook.
