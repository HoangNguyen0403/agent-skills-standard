# Production Spring Boot practices

Use externalized typed configuration and keep secrets out of source control. Prefer constructor injection, focused services, explicit DTOs, validation, clear transaction boundaries, and idempotent operations where retries are possible.

Add protected Actuator health, metrics, structured logs, tracing, timeouts, bounded pools, graceful shutdown, and resilience for dependency calls. Use migrations, least-privilege credentials, TLS, secure headers, dependency/image scanning, reproducible non-root images, resource limits, readiness/liveness probes, dashboards, alerts, and rollback procedures.

Test domain rules with unit tests, adapters with slice tests, infrastructure with integration tests, and service boundaries with contract tests. Verify configuration and startup behavior in a production-like environment.
