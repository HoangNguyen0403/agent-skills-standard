Common iOS UI navigation anti-patterns to avoid:

- Deep, confusing navigation stacks that make it hard to know where you are or get back.
- Using too many navigation patterns at once, like mixing tabs, modals, drawers, and nested flows without clear purpose.
- Hiding key actions or destinations behind gestures only, with no visible affordance.
- Pushing screens for temporary tasks that should be modals, or using modals for primary flow navigation.
- Breaking platform conventions, such as inconsistent back behavior or custom navigation controls that do not act like standard iOS patterns.
- Overloading the tab bar with too many items or unclear labels.
- Resetting user context when switching tabs or returning from a detail screen.
- Making navigation titles, hierarchy, or current location unclear.
- Forcing users through unnecessary steps instead of reducing friction with direct paths.
- Inconsistent transitions or unpredictable screen behavior that weakens orientation.
- Blocking navigation with full-screen interruptions, alerts, or permission prompts at the wrong time.
- Not adapting navigation well for different device sizes, orientations, or split-view contexts on iPad.
