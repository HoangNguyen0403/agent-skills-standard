Those explanation paragraphs should be removed.

Why: the workflow-writing standard says steps should be imperative and compact. If a bullet or command does the job, prose preambles are excess.

Use this structure instead:

Goal: State the outcome in one sentence.

Steps
- Use an action verb for each step.
- Keep each step to the command, check, or decision the agent must perform.
- Merge steps that always happen together.
- Move deep rationale to a reference file only if it is truly needed.

If a paragraph exists only to explain why a step exists, delete it. The workflow should tell the agent what to do, not narrate the process.
