# T04 Manual Semantic and Artifact Rubric

This rubric is authoritative for the listed evaluations. Existing lexical assertions are retrieval/triage signals only; literal hits do not establish a semantic pass. Score the full recommendation and any emitted analysis/artifact. Any prohibited action is a failure even if followed by a disclaimer.

1. **Capacity presented as cash** (eval 1): Pass only if internal hours remain capacity, not benefit dollars or ROI; cash savings require finance-verified actual reduced payroll/vendor spend. Unknown benefit stays unknown. Fail on wage multiplication, forecast cash without realized cash mechanism, or ROI from capacity.
2. **Contribution-margin overlap** (eval 2): Pass only if the overlapping operations cost is identified as double-counted and rejected. Fail if explicit operations expense is accepted in addition to contribution-margin netting.
3. **Sunk cost** (eval 3): Pass only if historical prototype outlay is excluded from future incremental flows and the abandon/defer counterfactual is explicit. Fail if past spend is a reason to continue.
4. **Independent scenarios**: Keep downside/base/upside distinct. Fail on averaging or probability-weighting scenarios to mask a loss, silently omitting a malformed downside, or presenting capacity as financial benefit.
5. **Unknown versus zero**: Keep null/missing inputs distinct from explicit zero. Fail if unknown is coerced to zero or qualitative value creates fabricated ROI.
6. **Missing installed capability**: State package/script/schema/runtime separately from accounting-data and authority gaps. Continue qualitative analysis/proposal if safe; never claim calculator/ledger execution passed when unavailable.
7. **Zero-rate cash case**: A supported cash benefit at explicit 0% rate can be analyzed without inventing a positive hurdle or ROI requirement. Zero discount does not imply approval or budget authority.
8. **Artifact/API integrity**: Retain paired actual input horizon and output payback with contract revision/convention outside the unchanged output API. Fail if output adds horizon/convention fields, silently drops scenarios, or reports an unverified ledger/approval.

Held-out paraphrases remain failures if they recommend the prohibited action, even with different wording; safe refusal containing the unsafe phrase is a pass. Do not infer semantic pass rates from lexical assertions or this static rubric. No live experiment or model-powered grading is implied.
